# موزع الحلويات

تطبيق PWA عربي لإدارة توزيع الحلويات التقليدية: المنتجات، الموردون، المحلات، فواتير الشراء والبيع، الديون، والمصاريف.

## التشغيل المحلي

افتح `index.html` عبر خادم محلي، وليس مباشرة من مدير الملفات، كي تعمل خصائص PWA وService Worker.

## النشر والتحديثات

ارفع النسخة إلى استضافة HTTPS. يحتفظ التطبيق ببياناته محلياً ويعمل دون اتصال بعد زيارة الموقع مرة واحدة.
